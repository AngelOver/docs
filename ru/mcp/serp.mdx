[MCP (Model Context Protocol)](https://modelcontextprotocol.io) — это протокол контекста модели, разработанный компанией Anthropic, который позволяет AI моделям (таким как Claude, GPT и др.) вызывать внешние инструменты через стандартизированный интерфейс. С помощью SERP MCP Server, предоставляемого XHuoAPI, вы можете выполнять поиск в Google прямо в AI-клиентах, таких как Claude Desktop, VS Code, Cursor и получать результаты поиска веб-страниц, изображений, новостей, видео, мест и т.д.

## Обзор функций

SERP MCP Server предоставляет следующие основные функции:

- **Поиск веб-страниц** — поиск результатов веб-страниц Google
- **Поиск изображений** — поиск изображений Google
- **Поиск новостей** — поиск новостей Google
- **Поиск видео** — поиск видео Google
- **Поиск мест** — поиск информации о местах Google
- **Поиск на картах** — поиск на картах Google
- **Многоязычность и много регионов** — поддержка настраиваемых параметров страны и языка
- **Фильтрация по временным диапазонам** — фильтрация результатов по дням, неделям, месяцам, годам

## Предварительная подготовка

Перед использованием вам необходимо получить токен API XHuoAPI:

1. Зарегистрируйтесь или войдите на [платформу XHuoAPI](https://api.xhuoapi.ai)
2. Перейдите на страницу [Google SERP API](https://api.xhuoapi.ai/documents/serp-google)
3. Нажмите «Acquire», чтобы получить токен API (при первом запросе предоставляется бесплатный лимит)

## Установка и настройка

### Способ 1: Установка через pip (рекомендуется)

```bash
pip install mcp-serp
```

### Способ 2: Установка из исходного кода

```bash
git clone https://github.com/XHuoAPI/SerpMCP.git
cd SerpMCP
pip install -e .
```

После завершения установки вы можете использовать команду `mcp-serp` для запуска сервиса.

## Использование в Claude Desktop

Отредактируйте файл конфигурации Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Добавьте следующую конфигурацию:

```json
{
  "mcpServers": {
    "serp": {
      "command": "mcp-serp",
      "env": {
        "XHuoAPI_API_TOKEN": "ваш API токен"
      }
    }
  }
}
```

Если вы используете `uvx` (не требуется предварительная установка пакета):

```json
{
  "mcpServers": {
    "serp": {
      "command": "uvx",
      "args": ["mcp-serp"],
      "env": {
        "XHuoAPI_API_TOKEN": "ваш API токен"
      }
    }
  }
}
```

Сохраните конфигурацию и перезапустите Claude Desktop, чтобы использовать инструменты поиска Google в диалоге.

## Список доступных инструментов

| Название инструмента      | Описание          |
| -------------------- | ----------- |
| `serp_google_search` | Поиск веб-страниц Google |
| `serp_google_images` | Поиск изображений Google |
| `serp_google_news`   | Поиск новостей Google |
| `serp_google_videos` | Поиск видео Google |
| `serp_google_places` | Поиск мест Google |
| `serp_google_maps`   | Поиск на картах Google |
