Το [MCP (Model Context Protocol)](https://modelcontextprotocol.io) είναι ένα πρωτόκολλο πλαισίου μοντέλου που έχει αναπτύξει η Anthropic, το οποίο επιτρέπει σε μοντέλα AI (όπως Claude, GPT κ.ά.) να καλούν εξωτερικά εργαλεία μέσω τυποποιημένων διεπαφών. Μέσω του Seedream MCP Server που παρέχεται από το XHuoAPI, μπορείτε να χρησιμοποιήσετε απευθείας τη δημιουργία και επεξεργασία εικόνων AI της ByteDance Seedream σε πελάτες AI όπως Claude Desktop, VS Code, Cursor κ.ά.

## Επισκόπηση Λειτουργιών

Ο Seedream MCP Server παρέχει τις ακόλουθες βασικές λειτουργίες:

- **Δημιουργία εικόνας από κείμενο** — Δημιουργία εικόνων υψηλής ποιότητας μέσω περιγραφών κειμένου (υποστηρίζει αγγλικά και κινέζικα)
- **Επεξεργασία εικόνας** — Τροποποίηση στυλ, φόντου, ιδιοτήτων κ.ά. σε υπάρχουσες εικόνες
- **Εικονική δοκιμή ρούχων** — Εφαρμογή ρούχων σε φωτογραφίες προσώπων
- **Υποστήριξη πολλαπλών μοντέλων** — Υποστηρίζει Seedream v4.5, v4.0, v3.0 T2I, SeedEdit v3.0 I2I κ.ά.
- **Πολλαπλές αναλύσεις** — Υποστήριξη 1K, 2K, 4K και προσαρμοστικών αναλύσεων
- **Έλεγχος σπόρου (seed)** — Επαναλήψιμα αποτελέσματα μέσω της παραμέτρου seed
- **Ερώτηση εργασιών** — Παρακολούθηση προόδου και λήψη αποτελεσμάτων

## Προαπαιτούμενα

Πριν τη χρήση, πρέπει να αποκτήσετε το XHuoAPI API Token:

1. Εγγραφείτε ή συνδεθείτε στην [πλατφόρμα XHuoAPI](https://api.xhuoapi.ai)
2. Μεταβείτε στη σελίδα [Seedream Images API](https://api.xhuoapi.ai/documents/seedream-images)
3. Πατήστε «Acquire» για να λάβετε το API Token (η πρώτη αίτηση παρέχει δωρεάν όριο)

## Εγκατάσταση και Ρύθμιση

### Μέθοδος 1: Εγκατάσταση μέσω pip (συνιστάται)

```bash
pip install mcp-seedream-pro
```

### Μέθοδος 2: Εγκατάσταση από πηγαίο κώδικα

```bash
git clone https://github.com/XHuoAPI/SeedreamMCP.git
cd SeedreamMCP
pip install -e .
```

Μετά την εγκατάσταση, μπορείτε να ξεκινήσετε την υπηρεσία με την εντολή `mcp-seedream-pro`.

## Χρήση στο Claude Desktop

Επεξεργαστείτε το αρχείο ρυθμίσεων του Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Προσθέστε την παρακάτω ρύθμιση:

```json
{
  "mcpServers": {
    "seedream": {
      "command": "mcp-seedream-pro",
      "env": {
        "XHuoAPI_API_TOKEN": "το API Token σας"
      }
    }
  }
}
```

Αν χρησιμοποιείτε `uvx` (χωρίς να απαιτείται προεγκατάσταση πακέτων):

```json
{
  "mcpServers": {
    "seedream": {
      "command": "uvx",
      "args": ["mcp-seedream-pro"],
      "env": {
        "XHuoAPI_API_TOKEN": "το API Token σας"
      }
    }
  }
}
```

Αποθηκεύστε και επανεκκινήστε το Claude Desktop για να χρησιμοποιήσετε τα εργαλεία Seedream στις συνομιλίες.

## Λίστα Διαθέσιμων Εργαλείων

| Όνομα Εργαλείου            | Περιγραφή                       |
|----------------------------|--------------------------------|
| `seedream_generate_image`  | Δημιουργία εικόνας από κείμενο |
| `seedream_edit_image`      | Επεξεργασία ή τροποποίηση εικόνας |
| `seedream_get_task`        | Ερώτηση κατάστασης μεμονωμένης εργασίας |
| `seedream_get_tasks_batch` | Μαζική ερώτηση κατάστασης εργασιών |
| `seedream_list_models`     | Λίστα όλων των διαθέσιμων μοντέλων και δυνατοτήτων |
| `seedream_list_sizes`      | Λίστα διαθέσιμων διαστάσεων και επιλογών ανάλυσης εικόνας |

## Παραδείγματα Χρήσης

Μετά τη ρύθμιση, μπορείτε να καλέσετε αυτές τις λειτουργίες σε πελάτες AI με φυσική γλώσσα, όπως:

- «Βοήθησέ με να δημιουργήσω μια εικόνα τοπίου σε στυλ μελάνης με το Seedream»
- «Άλλαξε το φόντο αυτής της φωτογραφίας σε αστρικό ουρανό»

- «Φόρεσε εικονικά αυτό το ρούχο στη φωτογραφία»
