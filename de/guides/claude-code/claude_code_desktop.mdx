Claude Code ist ein von Anthropic entwickeltes **Agentic Coding**-Tool, das auch als einer der stärksten Programmier-Agenten der Welt bezeichnet wird. Die Claude Code Desktop-Anwendung bietet eine eigenständige grafische Benutzeroberfläche, die Funktionen wie Diff-Überprüfung, parallele Sitzungen (isoliert durch Git Worktree) und Remote-Sitzungen unterstützt, ohne auf eine IDE angewiesen zu sein.

Dieses Dokument beschreibt hauptsächlich, wie man über den Proxy-Service von XHuoAPI die Claude Code Desktop-Anwendung konfiguriert und verwendet.

> **Hinweis**: Die Claude Code Desktop-Anwendung befindet sich derzeit in der Vorschauphase (Preview) und unterstützt nur macOS und Windows.

## Antragsprozess

Um Claude Code zu verwenden, können Sie zunächst auf die [Claude Messages-Dienstseite](https://api.xhuoapi.ai/documents/claude-messages) gehen und auf die Schaltfläche „Acquire“ klicken, um die erforderlichen Anmeldeinformationen zu erhalten:

![](https://cdn.xhuoapi.ai/nyq0xz.png)

Wenn Sie noch nicht angemeldet oder registriert sind, werden Sie automatisch zur Anmeldeseite weitergeleitet, um sich zu registrieren und anzumelden. Nach der Anmeldung werden Sie automatisch zur aktuellen Seite zurückgeleitet.

Bei der ersten Anfrage gibt es ein kostenloses Kontingent, um den Claude Code-Dienst kostenlos auszuprobieren.

## Installation der Desktop-Anwendung

### Systemanforderungen

- macOS (Intel und Apple Silicon) oder Windows (x64 / ARM64)
- Linux wird derzeit nicht unterstützt

### Download und Installation

Gehen Sie zur [offiziellen Download-Seite von Claude](https://claude.ai), um das Installationspaket für die entsprechende Plattform herunterzuladen:

- **macOS**: Laden Sie die `.dmg`-Datei herunter und ziehen Sie sie in den Ordner Anwendungen
- **Windows x64**: Laden Sie das `.exe`-Installationspaket herunter und folgen Sie den Anweisungen zur Installation
- **Windows ARM64**: Laden Sie die ARM64-Version herunter (Hinweis: ARM64 unterstützt keine lokalen Sitzungen, es muss eine Remote-Sitzung verwendet werden)

![Claude Desktop-Anwendungs-Downloadseite](https://cdn.xhuoapi.ai/c3c8c57264.png)

Nach der Installation starten Sie Claude aus dem Ordner Anwendungen (macOS) oder dem Startmenü (Windows).

## Konfiguration der XHuoAPI API

Nach dem Start der Desktop-Anwendung müssen Sie sich mit Ihrem Anthropic-Konto anmelden. Wir können Umgebungsvariablen konfigurieren, um die Proxy-API von XHuoAPI zu verwenden, **ohne offizielle Abonnements**.

Die Desktop-Anwendung liest Umgebungsvariablen aus Ihrer Shell-Umgebung, daher müssen Sie diese in der Shell-Konfigurationsdatei festlegen.

### Konfiguration der Umgebungsvariablen

**macOS-Benutzer**

Fügen Sie den folgenden Inhalt zu `~/.zshrc` (oder `~/.bashrc`) hinzu und ersetzen Sie `{token}` durch Ihr API-Token:

```bash
# XHuoAPI - Claude Code Proxy-Konfiguration
export ANTHROPIC_AUTH_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.xhuoapi.ai/v1"
```

Speichern Sie die Datei und führen Sie aus:

```bash
source ~/.zshrc
```

**Windows-Benutzer**

Fügen Sie über „Systemeigenschaften → Erweitert → Umgebungsvariablen“ die folgenden Systemumgebungsvariablen hinzu:

| Variablenname                | Wert                           |
| ---------------------- | ----------------------------- |
| `ANTHROPIC_AUTH_TOKEN` | `{token}` (ersetzen Sie durch Ihr API-Token)     |
| `ANTHROPIC_BASE_URL`   | `https://api.xhuoapi.ai/v1` |

Oder verwenden Sie PowerShell:

```powershell
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_AUTH_TOKEN", "{token}", "User")
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_BASE_URL", "https://api.xhuoapi.ai/v1", "User")
```

**Kann auch über settings.json konfiguriert werden**

Bearbeiten Sie `~/.claude/settings.json` (falls nicht vorhanden, erstellen Sie es):

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.xhuoapi.ai/v1"
  }
}
```

> **Hinweis**: Das API-Token kann im [XHuoAPI-Dashboard](https://api.xhuoapi.ai/console) eingesehen werden. Nach der Konfiguration müssen Sie die **Desktop-Anwendung neu starten**, damit die Umgebungsvariablen wirksam werden.

## Grundlegende Nutzung

### Projekt öffnen

1. Starten Sie die Claude Desktop-Anwendung
2. Klicken Sie auf die Registerkarte **Code** oben
3. Wählen Sie den Ausführungsmodus **Local**
4. Klicken Sie auf **Select folder**, um Ihr Projektverzeichnis auszuwählen

### Gespräch beginnen

Geben Sie im Eingabefeld eine natürliche Sprachbeschreibung Ihrer Anforderungen ein:

- „Finde TODO-Kommentare und behebe sie“
- „Füge Tests zur Hauptfunktion hinzu“
- „Erkläre die Architektur dieses Projekts“

Claude analysiert Ihr Code-Repository, schlägt Änderungen vor und zeigt die Änderungen im Diff-Ansicht an.

### Berechtigungsmodus

Wechseln Sie über den Moduswähler neben der Schaltfläche „Senden“:

| Modus       | Beschreibung                 |
| -------- | --------------------------- |
| **Ask**  | Fragt vor jeder Änderung um Bestätigung (empfohlen für Anfänger)  |
| **Code** | Akzeptiert automatisch Dateiänderungen, aber Terminalbefehle müssen bestätigt werden |
| **Plan** | Erstellt einen detaillierten Plan und wartet auf Genehmigung, bevor er ausgeführt wird |

### Parallele Sitzungen

Klicken Sie auf **+ New session** in der Seitenleiste, um mehrere parallele Sitzungen zu starten. Für Git-Repositories erhält jede Sitzung eine unabhängige Projektkopie über Worktree, die sich nicht gegenseitig stört.

Worktree wird standardmäßig im Verzeichnis `~/.claude-worktrees/` gespeichert.

### Diff-Überprüfung

Wenn Claude Dateien ändert, wird eine Änderungsstatistik angezeigt (z. B. `+12 -1`), und durch Klicken können Sie den Diff-Viewer öffnen, um die Änderungen dateiweise zu überprüfen. Sie können auch auf bestimmte Codezeilen klicken, um Kommentare hinzuzufügen, und Claude wird basierend auf Ihrem Feedback Anpassungen vornehmen.

## Verbindung zu externen Tools

Bevor Sie eine Sitzung beginnen, klicken Sie auf die Schaltfläche **⋯**, wählen Sie **Connectors**, um externe Integrationen hinzuzufügen:

- Google Kalender
- Slack
- GitHub
- Linear
- Notion
- Mehr...

Nach der Verbindung kann Claude direkt auf den Kalender zugreifen, Nachrichten senden, Issues erstellen usw.

## Beziehung zur CLI

Die Desktop-Anwendung und die CLI verwenden denselben zugrunde liegenden Motor und teilen die folgenden Konfigurationen:

- `CLAUDE.md` / `CLAUDE.local.md` Projektgedächtnisdateien
- `~/.claude.json` / `.mcp.json` MCP-Serverkonfiguration
- `~/.claude/settings.json` Einstellungen
- Hooks und Skills-Konfiguration

Beide können gleichzeitig im selben Projekt ausgeführt werden und pflegen jeweils eine unabhängige Sitzungshistorie.

## Häufige Fragen

### Was tun, wenn die Verbindung fehlschlägt?

1. Überprüfen Sie, ob die Datei `~/.claude/config.json` korrekt erstellt wurde
2. Stellen Sie sicher, dass die Umgebungsvariablen korrekt gesetzt sind (starten Sie die Desktop-Anwendung neu, um sie wirksam zu machen)
3. Überprüfen Sie, ob das API-Token gültig ist (kann im [Dashboard](https://api.xhuoapi.ai/console) eingesehen werden)
4. Wenn Sie die Umgebungsvariablen über `settings.json` konfiguriert haben, stellen Sie sicher, dass das Dateiformat korrekt ist

### Was tun, wenn installierte Tools nicht gefunden werden?

Wenn Claude `npm`, `node` usw. nicht finden kann:

1. Stellen Sie sicher, dass diese Tools im normalen Terminal funktionieren
2. Überprüfen Sie Ihre Shell-Konfigurationsdatei (`~/.zshrc`, `~/.bashrc`), ob der PATH korrekt gesetzt ist
3. Starten Sie die Desktop-Anwendung neu, um die Umgebungsvariablen neu zu laden

### Wie kann ich mein verbleibendes Kontingent einsehen?

Melden Sie sich im [XHuoAPI-Dashboard](https://api.xhuoapi.ai/console) an, um das aktuelle Kontingent und die Nutzung Ihres Kontos einzusehen.
