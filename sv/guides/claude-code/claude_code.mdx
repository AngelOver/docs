Claude Code är en programmeringsintelligent agent lanserad av Anthropic, som kan användas i terminaler, IDE:er, skrivbordsapplikationer och andra miljöer. Genom XHuoAPI-proxy kan du använda Claude Code till ett lägre pris.

> **Första gången?** Vi rekommenderar att du först läser [Claude Code 5-minuters snabbstart](https://api.xhuoapi.ai/documents/claude-code-5min-quickstart) — från att hämta dina autentiseringsuppgifter till att köra ditt första kommando, allt i fem steg.

Välj komplett konfigurationsguide för plattform baserat på användningsscenario:

| Plattform | Beskrivning | Guide-länk |
|-----------|-------------|------------|
| **⚡ 5-minuters snabbstart** | Från att hämta autentiseringsuppgifter till första `claude`-kommandot, fem steg | [5-minuters guide](https://api.xhuoapi.ai/documents/claude-code-5min-quickstart) |
| **Terminal (CLI)** | Kärnupplevelsen, kör `claude` i valfri terminal för att börja | [Terminalkonfigurationsguide](https://api.xhuoapi.ai/documents/claude-code-terminal-integration) |
| **VS Code** | Inbyggd extension med stöd för inline Diff, @-omnämnanden, planeringsgranskning | [VS Code konfigurationsguide](https://api.xhuoapi.ai/documents/claude-code-vscode-integrations) |
| **Cursor** | VS Code-kompatibel editor, fullt stöd för Claude Code extension | [Cursor konfigurationsguide](https://api.xhuoapi.ai/documents/claude-code-cursor-integration) |
| **JetBrains IDE** | Stöd för IntelliJ IDEA, PyCharm, WebStorm och hela IDE-familjen | [JetBrains konfigurationsguide](https://api.xhuoapi.ai/documents/claude-code-jetbrains-integrations) |
| **GitHub Actions** | Automatisera kodgranskning och Issue-hantering med `@claude` | [GitHub Actions konfigurationsguide](https://api.xhuoapi.ai/documents/claude-code-github-actions-integration) |
| **Skrivbordsapplikation (Preview)** | Fristående grafiskt klientprogram med stöd för parallella sessioner och externa verktyg | [Skrivbordsapplikationsguide](https://api.xhuoapi.ai/documents/claude-code-desktop-integration) |

> **Tips**: Ansök första gången via [Claude Messages tjänstesida](https://api.xhuoapi.ai/documents/claude-messages) och klicka på "Acquire" för att få autentiseringsuppgifter samt en gratis kvot.
