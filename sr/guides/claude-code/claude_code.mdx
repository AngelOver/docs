Claude Code је програмски интелигентни агент који је развио Anthropic, и може се користити у терминалу, IDE-у, десктоп апликацијама и другим окружењима. Кроз XHuoAPI прокси, можете користити Claude Code по нижој цени.

> **Први пут користите?** Препоручујемо да прво погледате [Claude Code 5 минута брзи почетак](https://api.xhuoapi.ai/documents/claude-code-5min-quickstart) — од добијања акредитива до успешног извршавања прве команде у пет корака.

Изаберите комплетно упутство за конфигурацију према вашем окружењу:

| Платформа | Опис | Линк ка упутству |
|-----------|-------|------------------|
| **⚡ Брзи почетак за 5 минута** | Од добијања акредитива до прве `claude` команде у пет корака | [5 минутно упутство](https://api.xhuoapi.ai/documents/claude-code-5min-quickstart) |
| **Терминал (CLI)** | Основно искуство, покрените `claude` у било ком терминалу и почните | [Упутство за терминал](https://api.xhuoapi.ai/documents/claude-code-terminal-integration) |
| **VS Code** | Натавни екстензија, подржава inline Diff, @-помена, планиране прегледе | [Упутство за VS Code](https://api.xhuoapi.ai/documents/claude-code-vscode-integrations) |
| **Cursor** | Уређивач компатибилан са VS Code-ом, потпуна подршка за Claude Code екстензију | [Упутство за Cursor](https://api.xhuoapi.ai/documents/claude-code-cursor-integration) |
| **JetBrains IDE** | Подржава IntelliJ IDEA, PyCharm, WebStorm и друге JetBrains IDE-ове | [Упутство за JetBrains](https://api.xhuoapi.ai/documents/claude-code-jetbrains-integrations) |
| **GitHub Actions** | Аутоматизујте преглед кода и обраду Issue-а помоћу `@claude` | [Упутство за GitHub Actions](https://api.xhuoapi.ai/documents/claude-code-github-actions-integration) |
| **Десктоп апликација (Преглед)** | Самостални графички клијент, подржава паралелне сесије и повезивање са спољним алатима | [Упутство за десктоп апликацију](https://api.xhuoapi.ai/documents/claude-code-desktop-integration) |

> **Напомена**: При првој пријави посетите [Claude Messages сервис страницу](https://api.xhuoapi.ai/documents/claude-messages) и кликните „Acquire“ да бисте добили акредитиве и бесплатни кредит.
