Claude Code on Anthropicin julkaisema **Agentic Coding** -työkalu, jota kutsutaan myös yhdeksi maailman vahvimmista ohjelmointiaineksista. Claude Code tarjoaa JetBrains IDE:lle erityisen liitännäisen, joka tukee koko JetBrains IDE -sarjaa, kuten IntelliJ IDEA, PyCharm, WebStorm, GoLand, PhpStorm ja Android Studio.

Tässä asiakirjassa esitellään, kuinka konfiguroidaan ja käytetään Claude Codea JetBrains IDE:ssä XHuoAPIin välityspalvelun kautta.

## Hakuprosessi

Claude Codea varten voit ensin siirtyä [Claude Messages -palvelusivulle](https://api.xhuoapi.ai/documents/claude-messages) ja napsauttaa "Acquire"-painiketta saadaksesi tarvittavat todisteet:

![](https://cdn.xhuoapi.ai/nyq0xz.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakukerralla saat ilmaisia krediittejä, joiden avulla voit kokeilla Claude Code -palvelua ilmaiseksi.

## Asennus

### Esivaatimukset

Claude Code JetBrains -liitännäinen riippuu Claude Code CLI:stä, joten varmista ensin, että CLI on asennettu:

```bash
# macOS / Linux / WSL
curl -fsSL https://claude.ai/install.sh | bash

# Tai käytä Homebrew'ta
brew install claude-code
```

Asennuksen jälkeen voit tarkistaa:

```bash
claude --version
```

### Liitännäisen asennus

![Claude Code -liitännäinen JetBrains Marketplace -sivustolla](https://cdn.xhuoapi.ai/de78fd305b.png)

1. Avaa JetBrains IDE
2. Siirry kohtaan **Settings** → **Plugins** → **Marketplace**
3. Etsi **Claude Code**
4. Napsauta **Install** asentaaksesi liitännäisen
5. Käynnistä IDE uudelleen

Tai siirry suoraan [JetBrains Marketplaceen](https://plugins.jetbrains.com/plugin/27310-claude-code-beta-) asentaaksesi sen verkossa.

> **Tärkeää**: Liitännäisen asentamisen jälkeen on tarpeen **käynnistää IDE täysin uudelleen** (saatat joutua käynnistämään useita kertoja) jotta se tulee voimaan.

## XHuoAPI API:n konfigurointi

Claude Code JetBrains -liitännäinen suorittaa `claude`-komennon integroidussa terminaalissa, joten ympäristömuuttujien konfigurointitapa on sama kuin CLI:ssä.

### Vaihe 1: Luo config.json

Luo Claude Code -konfiguraatiotiedosto:

| Järjestelmä          | Polku                                   |
| ----------------- | ------------------------------------ |
| **macOS / Linux** | `~/.claude/config.json`              |
| **Windows**       | `C:\Users\{käyttäjänimi}\.claude\config.json` |

Kirjoita tähän tiedostoon seuraava sisältö ja tallenna:

```json
{
  "primaryApiKey": "self"
}
```

macOS / Linuxin nopea luontikomento:

```bash
mkdir -p ~/.claude && echo '{"primaryApiKey": "self"}' > ~/.claude/config.json
```

### Vaihe 2: Ympäristömuuttujien konfigurointi

**Tapa 1: Aseta Shell-konfiguraatiotiedostoon (suositeltava)**

Lisää seuraava sisältö `~/.zshrc` tai `~/.bashrc` -tiedostoon, vaihda `{token}` omaan API-tokeniisi:

```bash
# XHuoAPI - Claude Code -välityskonfiguraatio
export ANTHROPIC_AUTH_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.xhuoapi.ai/v1"
```

Muokkauksen jälkeen suorita `source ~/.zshrc` saadaksesi asetukset voimaan, ja sitten **käynnistä JetBrains IDE uudelleen**.

**Tapa 2: Aseta Claude Code settings.json -tiedostoon**

Muokkaa `~/.claude/settings.json` (jos ei ole olemassa, luo se):

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.xhuoapi.ai/v1"
  }
}
```

> **Vihje**: API-tokenin voi tarkistaa [XHuoAPI -hallintapaneelista](https://api.xhuoapi.ai/console).

## Peruskäyttö

### Käynnistä IDE:n sisäisestä terminaalista

Avaa JetBrains IDE:n integroitu terminaali ja suorita:

```bash
claude
```

Kun suoritat IDE:n integroituun terminaaliin, kaikki integrointitoiminnot (Diff-näkymä, kontekstin valinta jne.) aktivoituvat automaattisesti.

### Yhdistä ulkoisesta terminaalista

Jos suoritat Claude Codea ulkoisessa terminaalissa, voit käyttää `/ide`-komentoa yhdistääksesi JetBrains IDE:hen:

```bash
claude
> /ide
```

Varmista, että käynnistät Claude Coden samasta polusta IDE-projektin juurihakemistosta, jotta Claude pääsee käsiksi samoihin tiedostoihin.

### Pikanäppäimet

| Pikanäppäin                                          | Toiminto                      |
| ------------------------------------------------ | ----------------------- |
| `Cmd+Esc` (Mac) / `Ctrl+Esc` (Windows/Linux)        | Avaa nopeasti Claude Code        |
| `Cmd+Option+K` (Mac) / `Alt+Ctrl+K` (Windows/Linux) | Lisää tiedostoviittaus (esim. `@File#L1-99`) |

### Integrointitoiminnot

Claude Code JetBrains -liitännäinen tarjoaa seuraavat integrointitoiminnot:

- **Diff-näkymä**: Koodimuutokset näytetään suoraan IDE:n Diff-näkymässä
- **Kontekstin valinta**: Tällä hetkellä valittu koodi ja välilehdet jaetaan automaattisesti Claudelle
- **Tiedostoviittaus**: Käytä pikanäppäimiä tiedostojen ja rivinumeroiden nopeaan viittaamiseen
- **Diagnostiikan jakaminen**: IDE:ssä olevat Lint-, syntaksivirheet jne. diagnostiikkatiedot jaetaan automaattisesti Claudelle

## Liitännäisen asetukset

Voit konfiguroida seuraavat asetukset kohdassa **Settings** → **Tools** → **Claude Code [Beta]**:

| Asetus                          | Selitys                                         |
| ----------------------------- | ------------------------------------------ |
| **Claude command**            | Mukautettu Claude-komennon polku (esim. `/usr/local/bin/claude`) |
| **Ota automaattiset päivitykset käyttöön**  | Tarkista ja asenna liitännäispäivitykset automaattisesti                                |
| **Ota käyttöön Option+Enter** | Käytä macOS:ssä Option+Enter vaihtaaksesi riville kehotteessa             |

### WSL-käyttäjien konfigurointi

Jos käytät WSL-ympäristössä, aseta Claude command seuraavaksi:

```
wsl -d Ubuntu -- bash -lic "claude"
```

(Vaihda `Ubuntu` omaan WSL-jakelun nimeesi)

## Usein kysytyt kysymykset

### Mitä tehdä, jos yhteys epäonnistuu?

1. Tarkista, onko `~/.claude/config.json` -tiedosto luotu oikein
2. Varmista, että ympäristömuuttujat on asetettu oikein
3. Varmista, että API-token on voimassa (voit tarkistaa sen [hallintapaneelista](https://api.xhuoapi.ai/console))
4. Käynnistä JetBrains IDE uudelleen ja yritä uudelleen

### Mikäli liitännäinen ei toimi?

1. Varmista, että suoritat Claude Codea projektin juurihakemistosta
2. Tarkista, että liitännäinen on käytössä IDE:n asetuksissa
3. Käynnistä IDE täysin uudelleen (saatat joutua käynnistämään useita kertoja)
4. Jos käytät etäkehitysmoodia, varmista, että liitännäinen on asennettu etäisäntään (Asetukset → Liitännäinen (Isäntä))

### IDE:tä ei havaita?

1. Varmista, että liitännäinen on asennettu ja käytössä
2. Käynnistä IDE uudelleen
3. Varmista, että suoritat Claude Codea integroituun terminaaliin
4. WSL-käyttäjät, katso [WSL-vianetsintäopas](https://code.claude.com/docs/en/troubleshooting#jetbrains-ide-not-detected-on-wsl2)

### command not found

Jos napsautat Claude-kuvaketta ja saat ilmoituksen "command not found":

1. Varmista, että CLI on asennettu: `which claude`
2. Määritä liitännäisen asetuksissa Claude-komennon täydellinen polku
3. WSL-käyttäjät käyttävät yllä olevia WSL-komentomuotoja
### Kuinka tarkistaa jäljellä oleva saldo?

Kirjaudu sisään [XHuoAPI -hallintapaneeliin](https://api.xhuoapi.ai/console), niin voit tarkistaa nykyisen tilisi jäljellä olevan saldon ja käyttötilanteen.
