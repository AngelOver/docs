Claude Code on Anthropicin julkaisema **Agentic Coding** -työkalu, jota kutsutaan myös yhdeksi maailman vahvimmista ohjelmointiaineksista. Claude Code työpöytäsovellus tarjoaa itsenäisen graafisen käyttöliittymän, joka tukee Diff-tarkastelua, rinnakkaisia istuntoja (Git Worktree -eristyksen kautta), etäistuntoja ja muita toimintoja ilman, että se riippuu mistään IDE:stä.

Tässä asiakirjassa esitellään, kuinka konfiguroidaan ja käytetään Claude Code työpöytäsovellusta XHuoAPIin välityspalvelun kautta.

> **Huomio**: Claude Code työpöytäsovellus on tällä hetkellä esikatseluvaiheessa (Preview) ja tukee vain macOS:ää ja Windowsia.

## Hakuprosessi

Käyttääksesi Claude Codea, voit ensin siirtyä [Claude Messages -palvelusivulle](https://api.xhuoapi.ai/documents/claude-messages) ja napsauttaa "Acquire"-painiketta saadaksesi tarvittavat todisteet:

![](https://cdn.xhuoapi.ai/nyq0xz.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakemiskerralla saat ilmaisia krediittejä, joiden avulla voit kokeilla Claude Code -palvelua ilmaiseksi.

## Työpöytäsovelluksen asennus

### Järjestelmävaatimukset

- macOS (Intel ja Apple Silicon) tai Windows (x64 / ARM64)
- Linux ei tue työpöytäsovellusta

### Lataa ja asenna

Siirry [Claude viralliselle lataussivulle](https://claude.ai) ja lataa vastaavan alustan asennustiedosto:

- **macOS**: Lataa `.dmg`-tiedosto ja vedä se Applications-kansioon
- **Windows x64**: Lataa `.exe`-asennustiedosto ja asenna ohjeiden mukaan
- **Windows ARM64**: Lataa ARM64-versio (huom: ARM64 ei tue paikallisia istuntoja, vaan etäistuntoja on käytettävä)

![Claude työpöytäsovelluksen lataussivu](https://cdn.xhuoapi.ai/c3c8c57264.png)

Asennuksen jälkeen käynnistä Claude Applications-kansiosta (macOS) tai Käynnistä-valikosta (Windows).

## XHuoAPI API:n konfigurointi

Työpöytäsovelluksen käynnistyessä sinun on kirjauduttava Anthropic-tilillesi. Voimme käyttää XHuoAPIin välityspalvelu API:a konfiguroimalla ympäristömuuttujat, **ilman virallista tilausta**.

Työpöytäsovellus lukee ympäristömuuttujat Shell-ympäristöstäsi, joten ne on asetettava Shellin konfiguraatiotiedostoon.

### Ympäristömuuttujien konfigurointi

**macOS-käyttäjät**

Lisää seuraava sisältö `~/.zshrc`- (tai `~/.bashrc`) tiedostoon, vaihtaen `{token}` omaksi API-tunnuksesi:

```bash
# XHuoAPI - Claude Code välityspalvelun konfigurointi
export ANTHROPIC_AUTH_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.xhuoapi.ai/v1"
```

Tallenna ja suorita:

```bash
source ~/.zshrc
```

**Windows-käyttäjät**

Lisää seuraavat järjestelmäympäristömuuttujat "Järjestelmän ominaisuudet → Lisäasetukset → Ympäristömuuttujat":

| Muuttujan nimi            | Arvo                           |
| ---------------------- | ----------------------------- |
| `ANTHROPIC_AUTH_TOKEN` | `{token}` (vaihda omaksi API-tunnuksesi) |
| `ANTHROPIC_BASE_URL`   | `https://api.xhuoapi.ai/v1`  |

Tai käytä PowerShellia:

```powershell
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_AUTH_TOKEN", "{token}", "User")
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_BASE_URL", "https://api.xhuoapi.ai/v1", "User")
```

**Voit myös konfiguroida settings.json-tiedostolla**

Muokkaa `~/.claude/settings.json` (luo se, jos sitä ei ole):

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.xhuoapi.ai/v1"
  }
}
```

> **Vinkki**: API-tunnuksen voi tarkistaa [XHuoAPIin hallintapaneelista](https://api.xhuoapi.ai/console). Konfiguroinnin jälkeen on tarpeen **käynnistää työpöytäsovellus uudelleen** ympäristömuuttujien voimaantulemiseksi.

## Peruskäyttö

### Avaa projekti

1. Käynnistä Claude työpöytäsovellus
2. Napsauta yläreunassa olevaa **Code**-välilehteä
3. Valitse **Local**-käyttötila
4. Napsauta **Select folder** valitaksesi projektikansiosi

### Aloita keskustelu

Kirjoita syöttökenttään luonnollisella kielellä kuvaus tarpeistasi:

- "Löydä TODO-kommentit ja korjaa ne"
- "Lisää testit pääfunktioon"
- "Selitä tämän projektin arkkitehtuuri"

Claude analysoi koodikirjastosi, ehdottaa muutoksia ja esittää muutokset Diff-näkymässä.

### Oikeusmoodi

Vaihda tilanvalitsimella, joka on lähempänä lähetä-painiketta:

| Moodi       | Selitys                     |
| -------- | -------------------------- |
| **Ask**  | Kysy vahvistusta ennen jokaista muutosta (suositellaan aloittelijoille) |
| **Code** | Hyväksyy automaattisesti tiedostojen muokkaukset, mutta terminaalikomennot vaativat edelleen vahvistuksen |
| **Plan** | Laadi ensin yksityiskohtainen suunnitelma odottamaan hyväksyntää, suoritetaan vasta vahvistuksen jälkeen |

### Rinnakkaiset istunnot

Napsauta sivupalkissa **+ New session** käynnistääksesi useita rinnakkaisia istuntoja. Git-repositorioissa jokainen istunto saa Worktree:n kautta itsenäisen projektikopion, joka ei häiritse toisiaan.

Worktree tallennetaan oletusarvoisesti `~/.claude-worktrees/` -hakemistoon.

### Diff-tarkastus

Kun Claude muuttaa tiedostoja, se näyttää muutosten tilastot (esim. `+12 -1`), napsauttamalla voit avata Diff-näkymän tarkastellaksesi muutoksia tiedostokohtaisesti. Voit myös napsauttaa tiettyjä koodirivejä lisätäksesi kommentteja, ja Claude säätää ehdotuksia palautteesi perusteella.

## Yhdistä ulkoisiin työkaluihin

Ennen istunnon aloittamista napsauta **⋯**-painiketta ja valitse **Connectors** lisätäksesi ulkoisia integraatioita:

- GitHub
- Linear

Yhdistämisen jälkeen Claude voi suoraan lukea kalenteria, lähettää viestejä, luoda ongelmia jne.

## Suhde CLI:hin

Työpöytäsovellus ja CLI käyttävät samaa taustamoottoria ja jakavat seuraavat asetukset:

- `CLAUDE.md` / `CLAUDE.local.md` projektimuistitiedostot
- `~/.claude.json` / `.mcp.json` MCP-palvelin asetukset
- `~/.claude/settings.json` asetukset
- Hooks ja Skills -asetukset

Molemmat voivat toimia samassa projektissa samanaikaisesti, ja ne ylläpitävät itsenäistä istuntohistoriaa.

## Usein kysytyt kysymykset

### Mitä tehdä, jos yhteys epäonnistuu?

1. Tarkista, onko `~/.claude/config.json` tiedosto luotu oikein
2. Varmista, että ympäristömuuttujat on asetettu oikein (käynnistä työpöytäsovellus uudelleen, jotta ne tulevat voimaan)
3. Varmista, että API-tunnus on voimassa (voit tarkistaa sen [hallintapaneelista](https://api.xhuoapi.ai/console))
4. Jos käytät `settings.json`-tiedostoa ympäristömuuttujien konfiguroimiseen, varmista, että tiedostomuoto on oikea

### En löydä asennettuja työkaluja?

Jos Claude ei löydä `npm`-, `node`-komentoja jne.:

1. Varmista, että nämä työkalut toimivat normaalissa terminaalissa
2. Tarkista Shellin konfiguraatiotiedostosi (`~/.zshrc`, `~/.bashrc`), onko PATH asetettu oikein
3. Käynnistä työpöytäsovellus uudelleen ympäristömuuttujien lataamiseksi

### Kuinka tarkistaa jäljellä oleva saldo?

Kirjaudu sisään [XHuoAPI hallintapaneeliin](https://api.xhuoapi.ai/console) nähdäksesi nykyisen tilisi jäljellä olevan saldon ja käyttötilanteen.
