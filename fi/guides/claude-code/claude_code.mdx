Claude Code on Anthropicin kehittämä ohjelmointiapuri, jota voi käyttää monissa ympäristöissä, kuten terminaalissa, IDE:ssä ja työpöytäsovelluksissa. XHuoAPI -välityspalvelun kautta voit käyttää Claude Codea edullisemmin.

> **Ensimmäistä kertaa käytössä?** Suosittelemme tutustumaan ensin [Claude Code 5 minuutin pikaoppaaseen](https://api.xhuoapi.ai/documents/claude-code-5min-quickstart) — viisi askelta tunnuksen hankinnasta ensimmäisen komennon onnistuneeseen suorittamiseen.

Valitse käyttötarkoitukseesi sopiva alustan täydellinen asennusopas:

| Alusta | Kuvaus | Opaslinkki |
|--------|--------|------------|
| **⚡ 5 minuutin pika-aloitus** | Tunnuksen hankinnasta ensimmäiseen `claude`-komentoon viidessä vaiheessa | [5 minuutin opas](https://api.xhuoapi.ai/documents/claude-code-5min-quickstart) |
| **Terminaali (CLI)** | Ydinympäristö, aloita suorittamalla `claude` missä tahansa terminaalissa | [Terminaaliasennusopas](https://api.xhuoapi.ai/documents/claude-code-terminal-integration) |
| **VS Code** | Natiivilaajennus, tukee sisäisiä diff-vertailuja, @-mainintoja ja tarkastelusuunnitelmia | [VS Code -asennusopas](https://api.xhuoapi.ai/documents/claude-code-vscode-integrations) |
| **Cursor** | VS Code -yhteensopiva editori, Claude Code -laajennus täysin tuettu | [Cursor-asennusopas](https://api.xhuoapi.ai/documents/claude-code-cursor-integration) |
| **JetBrains IDE** | Tukee IntelliJ IDEA:ta, PyCharmia, WebStormia ja muita JetBrainsin IDE:itä | [JetBrains-asennusopas](https://api.xhuoapi.ai/documents/claude-code-jetbrains-integrations) |
| **GitHub Actions** | Automatisoi koodin tarkastus ja issue-käsittely `@claude`-komennolla | [GitHub Actions -asennusopas](https://api.xhuoapi.ai/documents/claude-code-github-actions-integration) |
| **Työpöytäsovellus (Esikatselu)** | Erillinen graafinen asiakasohjelma, tukee rinnakkaisia istuntoja ja ulkoisia työkaluja | [Työpöytäsovellusopas](https://api.xhuoapi.ai/documents/claude-code-desktop-integration) |

> **Vinkki**: Hanki tunnus ensimmäisellä kerralla käymällä [Claude Messages -palvelusivulla](https://api.xhuoapi.ai/documents/claude-messages) ja napsauttamalla "Acquire" saadaksesi tunnuksen sekä ilmaisen käyttökiintiön.
