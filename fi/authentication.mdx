---
title: "Todennus"
description: "Kuinka käyttää XHuoAPI API:ta todennukseen"
---

Kaikki XHuoAPI API:t käyttävät **Bearer Token** -todennusta.

## Tokenin hankkiminen

1. Rekisteröidy osoitteessa [platform.xhuoapi.ai](https://api.xhuoapi.ai)
2. Tilaa tarvittavat palvelut
3. Luo jokaiselle palvelulle tunnisteet (API Token)

## Tokenin käyttäminen

Sisällytä Token jokaisen pyynnön `Authorization`-otsikkoon:

```bash
Authorization: Bearer YOUR_API_TOKEN
```

<Note title="Vinkki">
  Jokainen Token on sidottu tiettyyn palvelutilaukseen. Eri palvelut käyttävät eri Tokeneita, tai voit luoda **globaalin** tunnisteen palveluiden väliseen käyttöön.
</Note>

## Nopeusrajoitukset

Nopeusrajoitukset vaihtelevat palvelun ja tilausluokan mukaan. Rajoituksen ylittäessä API palauttaa `429 Too Many Requests` -vastauksen.

## Turvallisuuden parhaat käytännöt

- Älä paljasta API Tokenia asiakaskoodissa
- Tallenna Token ympäristömuuttujiin
- Kierrätä Tokenia säännöllisesti
- Käytä eri Tokeneita kehitys- ja tuotantoympäristöissä
